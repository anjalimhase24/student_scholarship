# 🎓 Student Scholarship Website
## 📌 Project Description

The Student Scholarship Website is a web-based project developed to provide students with complete information about various scholarships.
It helps students understand eligibility criteria and apply for scholarships easily through an online application form.
The project is simple, user-friendly, and designed especially for students.

## 🎯 Objectives of the Project

To provide scholarship-related information in one place

To help students check eligibility easily

To allow students to apply for scholarships online

To create a simple and beginner-friendly website using HTML and CSS

## 🛠️ Technologies Used

HTML5 – For creating the structure of web pages

CSS3 – For styling and layout

Git & GitHub – For version control and project hosting

## 📄 Website Pages

Home Page (index.html) – Introduction to the scholarship portal

About Page (about.html) – Information about scholarships

Eligibility Page (eligibility.html) – Eligibility criteria for students

Apply Page (apply.html) – Scholarship application form

Contact Page (contact.html) – Contact and support details

## ✨ Features

Simple and clean user interface

Scholarship information available for students

Eligibility criteria clearly mentioned

Online scholarship application form

Easy navigation between pages
